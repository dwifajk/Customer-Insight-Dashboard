# Customer Insight Dashboard – Customer Profiling
Interactive Power BI dashboard developed as a hands-on project during a Data Analytics Bootcamp.

## Project Overview
This project focuses on analyzing customer profiles, segmentation, product portfolio, regional distribution, demographics, and customer trends using Microsoft Power BI.

## Key Analysis
- Customer profiling by grade
- Customer segmentation
- Balance distribution by region
- Product portfolio analysis
- Customer demographics
- Customer acquisition trend
- Customer distribution by age
- Customer flag analysis

## Dashboard Features
### Customer Overview
- Total Balance
- Total Customers
- Average Customer Age
- Top Customer Segment
- Top Product

### Customer Analysis
- Balance by Region
- Customers by Segment
- Balance & Customers by Product
- Customers by Gender
- Customer Acquisition Trend
- Customers by Age

### Customer Profiling
- Customer Grade by Region
- Customer Flag Distribution
- Customer Profiling Summary

This dashboard was developed as a hands-on project during a Data Analytics Bootcamp to apply data visualization, data transformation, and business intelligence concepts using Power BI.
